# Awesome design skills (vendored, MIT, typeui.sh)
Each folder `<style>/SKILL.md` + `DESIGN.md` describes one visual style's tokens and component rules.
Use: the art-director archetype lists style seeds; read those folders and borrow component-level details
(button shape, focus rings, input styling, border weights). Palette and type come from your dealt lane and
type system, never from these sheets. Layout comes from the archetype.
