# Island Previews: website concept factory

This repo produces **concept preview websites** for 100 Bahamian businesses (list in `factory/data/prospects.json`).
Each site is a sales asset: Balazs shows it to the owner to win a $500-$1,000+ rebuild contract.
GitHub Pages serves the repo root, so `/<slug>/index.html` becomes `https://<owner>.github.io/<repo>/<slug>/`.

## Your job in a session
You are given a BATCH number (for example `07`). Build every prospect in `prospects.json` whose `batch` matches, one after another, fully finishing and pushing each before starting the next. **Immediately before starting each business, run `node factory/tools/batch.mjs claim <slug>`. If it prints SKIP, another session has it: move on to the next one.** In resume mode (`batch.mjs pending N`) the same claim rule applies.
**Always load the `site-factory` skill first** (`.claude/skills/site-factory/SKILL.md`) and follow its pipeline exactly, and the `art-director` skill (`.claude/skills/art-director/SKILL.md`) for every business. The full unattended brief is `factory/PROMPT.md`.

**Generation 2.** The first 55 sites shared one template and are being rebuilt from scratch. `batch.mjs pending` lists them again alongside the unbuilt ones. The art-director skill explains what went wrong; never reproduce it.

## The bar
Every site is portfolio work a client would pay $1,000+ for: built for that business's real buyer (a marina sells to yacht owners, so it must feel quietly luxurious), with visuals that depict the business's actual setting and trade (never random effects), at least two real interactions, led by photographs of the real place and trade, and a design unlike any other site in this repo: this is a small island nation and owners compare. Every business is dealt its own page archetype, palette lane, type system, navigation and motion (`node factory/tools/direction.mjs <slug>`), studies two award-level sites for that archetype, passes `factory/tools/distinct.mjs` and a fresh-eyes critic subagent, and scores 4/5 or higher on the showcase scorecard.

## Priority and saving
Batches are ordered by priority: businesses with no working website first, then outdated sites, then the rest, then large enterprises. Every finished business is pushed immediately, so if credits run out, everything completed so far is already live and saved.

## Hard rules (never break)
1. **Truth only.** Every fact on a site (name, address, phone, email, hours, services, rooms, prices, awards, years, staff names) must come from research done in this session (firecrawl_scrape / WebSearch) or from `prospects.json`. Never invent reviews, testimonials, star ratings, awards, prices, statistics, client logos, or staff. If a fact is unknown, design around it or use a clearly marked neutral line such as "Rates on request". For businesses with no website (Track B in the skill), category-standard service lines inferred from a confirmed business category are allowed, phrased as categories only (no numbers, brands, years, certifications, guarantees), and every one is listed as an assumption to confirm with the owner.
2. **Concept label.** Every page carries the shared concept ribbon (see skill). It states the site is an unsolicited concept by the agency, not the business's official website. Never remove it.
3. **No indexing.** Every page has `<meta name="robots" content="noindex, nofollow">`. Root `robots.txt` disallows all. These previews must never compete with the real business in Google. The production-ready SEO (titles, descriptions, JSON-LD, canonical to the real domain) is still written in full, because that is what we are selling.
4. **Stack: React + Vite + Tailwind v4 + shadcn/ui + Motion + three.js (React Three Fiber) + Lenis**, shared toolchain in `factory/web/`. Each site's source lives in `factory/web/sites/<slug>/` and is built to static `/<slug>/` with `node factory/tools/build-site.mjs <slug>` (it also prerenders every page so the shipped HTML contains all text for SEO). Vendored component libraries: `factory/web/src/components/ui` (shadcn), `/magicui` (Magic UI), `/reactbits` (React Bits backgrounds, gradients, text animations). See `.claude/skills/site-factory/references/components-catalog.md`. Never edit files in `factory/web/src/`, only import them. Google Fonts via `<link>` is allowed.
5. **Never open another site's source.** Do not read any other business's `factory/web/sites/<slug>/` or built `/<slug>/` code: generation 1 copied one reference site and every page came out the same. Design from your dealt direction and the award-level sites you study.
6. **Research tools (unattended runs):** never use the WebFetch tool: it stops the session for a manual approval on every new domain. Read pages with the Firecrawl connector `firecrawl_scrape` (formats ["markdown","links","images"], onlyMainContent true) and search with `WebSearch` or `firecrawl_search`. The sandbox shell cannot reach the internet (except GitHub and package registries), so never curl. Do not try workarounds (mirrors, caches, proxies) for sites the tools refuse.
7. **Images: photographs first** (exact procedures in `.claude/skills/art-director/references/imagery.md`). Allowed sources: (a) image URLs seen verbatim on the business's own website or official social pages; (b) Wikimedia Commons photos of the real place under CC0, CC BY, CC BY-SA or public domain, credited with artist and licence on the page; (c) photoreal images generated in a Lovable asset project for this business, showing the trade and its subject, never presented as the client's own property, staff, rooms or boats, listed as "illustrative photography, replace with your own" in status and concept notes; (d) procedural 3D of a real object (img2threejs). Never hotlink Google Maps, TripAdvisor, Booking or news-site photos. Never stock libraries, placeholders, SVG drawings of scenes, buildings, vehicles or landscapes, or toy low-poly 3D.
8. **Budget discipline.** Per business: at most ~12 research fetches/searches (rebuilds with an existing brief: about 6), plus imagery calls (Commons searches, one Lovable asset project of at most two rounds), one build, one QA run, one distinctness run, at most two fix passes. Tier C businesses get a single-page concept and at most 5 research calls.
9. **Only touch your own folders:** `factory/web/sites/<slug>/`, the built `/<slug>/`, `factory/briefs/<slug>.md`, `factory/status/<slug>.json` and `factory/directions/<slug>.json` for each business in your batch. Never edit another business's folder. Never edit `prospects.json`.
10. **Push after every business**, not at the end (`factory/tools/publish.sh <slug>`). If credits run out mid-batch, finished work must already be live.
11. No em dashes (the "—" character) anywhere in site copy. Use commas, colons, or full stops.

## Anti-patterns banned on every site
Dark overlays on hero images. Orange/red as the accent color (unless it is the business's real brand color). Card-grid menus or card-grid "services" that look like a SaaS template. Bold condensed uppercase display fonts. Full-dark backgrounds for the whole site, unless the dealt palette lane has a dark ground (P04, P05, P13, P14), which must still include one light section. "Book a Table" CTA copy. Star-rating testimonial sections. Generic placeholder or stock images. Purple/blue AI gradients. Inter/Roboto/Arial/system as the display face. Three-icon "feature" rows with emoji. "Welcome to our website". Lorem ipsum. Fake counters ("500+ happy clients") without a sourced number.

Every generation-1 clone is also banned (and blocked by `distinct.mjs`): a "Key information" band under the hero, the sticky blurred header with pill button, the shared `Reveal` fade-up-blur, the 1440 px + 40 px container, tracked uppercase eyebrows above every heading (unless the type system uses them), "<Name>, <place>, since <year>" headlines, near-white page grounds outside lanes P01/P10/P12, SVG scene illustrations.
