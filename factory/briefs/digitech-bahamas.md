# Generation 2 design plan (2026-11-21)

Re-checked digitechbahamas.com (redirects to /bs/): facts above confirmed; counters now read 25+ projects, 1426+ developer hours, 27+ clients (theme counters, not used). Own uploads: POS-Shot.png, cloud-backup-services.jpeg. Everything else is theme stock.

**Big idea:** scrolling X-rays one Nassau counter: the Razor POS till Digitech installs, then the cable under it, the Wi-Fi with its separate VLANs and firewall, and the cloud backup behind it, each drawn onto the photograph as a precise leader line, so an owner sees in ten seconds everything Digitech builds behind a till.

**Direction:** A06 Object study + P01 Limestone + T04 Technical mono (N4 floating bottom dock, M9 line and overlay drawing). Why: Digitech sells physical systems (a terminal, cabling, access points), so the object study explains the product; limestone ground with one sea-glass accent (#2F6F73) reads Bahamian and calm, not "tech dark mode"; Sora display with IBM Plex Sans and Plex Mono only for callout labels and phone numbers (data people copy).

**Fonts:** Sora variable (display 600, tight -0.035em), IBM Plex Sans 400/500 (body 18px), IBM Plex Mono 400/500 (callout labels, phone numbers, tabular). Self-hosted.
